# OPENAI_MODEL is read outside the settings path

src/optimization/explain_agent.py `OPENAI_MODEL` and `ExplainResultsAgent.__init__`: the module calls `load_dotenv()` and reads `OPENAI_MODEL` with `os.getenv` at import time, and reads `OPENAI_API_KEY` with `os.getenv` again, while every other setting goes through config/settings.py and ui/services/runtime_config.py (`OPENAI_WPS_MODEL` has a default there, `openai_api_key()` is the accessor for the key). `override_settings` cannot reach the value in tests, and with the variable unset the explanation fails with "OPENAI_MODEL non configurato" although .env.example suggests a default. Add `OPENAI_MODEL` (default as in .env.example) to config/settings.py and to `RuntimeConfig`, pass model and key to `ExplainResultsAgent` from ui/services/optimization_explanation.py, and remove `load_dotenv()` and the module-level constant.
