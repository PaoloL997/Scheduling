# Remove the dead deadline editor and stats filter from the Gantt

ui/static/ui/gantt.js `openDeadlineEditor`, `closeDeadlineEditor`, `saveDeadline`, `setStatFilter`, `updateStats`, `_syncStatFilterUI` and their wiring in `bindControls`, plus ui/templates/ui/index.html `#dl-popover` (markup and CSS): dead code. The only chart created by a template passes `enableStats: false` and `enableDeadlineEditor: false`, no element ever carries `data-dl-job-id`, no template contains `#stats-row`, and the popover buttons call the globals `saveDeadline()` / `closeDeadlineEditor()`, which do not exist. Remove the deadline editor and the stats filter from gantt.js, the popover from index.html, the `enableStats` / `enableDeadlineEditor` options (also from the fixtures that pass them) and ui/tests/fixtures/gantt_stat_filter_test.mjs with its Python test; deadlines stay editable from Pianificazione. After the removal nothing in the UI calls `/api/commesse/deadline/` (`api_commesse_deadline` in ui/views.py): remove the route, the view and `_handle_deadline_update` too if no test or tablet client still needs them, otherwise leave them and say so in the PR.
