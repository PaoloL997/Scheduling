# Overrunning in-progress activity disappears from the week, month and year views

ui/static/ui/gantt.js `render` (row visibility test `if (visStart >= maxD || visEnd <= minD) return null;` and the `allFinish` extent of the commessa summary just below): the end of a started activity is taken from `executionEndDate`, i.e. `effective_finish`, while the drawing code extends an activity that is still open past that date up to today (`_overrunEndDate`). In the Settimana, Mese and Anno views an activity in progress whose estimated end falls before the start of the window is therefore dropped, although it is running today and its overrun tail should cross the window; the default horizon view is not affected. Use `_overrunEndDate(...) || executionEnd` for `visEnd` and for `allFinish`. For the same reason ui/tests/fixtures/gantt_overrun_test.mjs (activity ended 30 days ago, year view) fails when run in January or early February: after the fix it must pass on any day, so add a case that pins the window start after the estimated end.
