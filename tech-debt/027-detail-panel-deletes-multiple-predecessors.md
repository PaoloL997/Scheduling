# Detail panel silently deletes the predecessors of an activity that has several

ui/templates/ui/pianificazione.html `enterEditMode` (the `predecessors` select) and `saveEdit`: predecessors are a many-to-many relation exchanged as `activity_id`s joined by ", ", but the detail panel shows a single select matched by exact string (`a.activity_id === currentPred`). For an activity with two or more predecessors nothing matches, "— Nessuno —" is selected, and saving any other field sends `predecessors: []`, which `update_attivita` in ui/services/bridge_write.py applies: the links are silently deleted. Include `predecessors` in the payload only when the select value differs from the one it was rendered with, and when the activity has more than one predecessor render them as read-only text instead of the select.
