# Temporary WPS PDFs are never cleaned up

ui/views_attivita.py `api_analizza_wps` and `api_salva_attivita`, ui/templates/ui/pianificazione.html `WIZ.tmpPath`: the uploaded WPS PDF is saved as `media/wps/_tmp_<name>` and deleted only when the activity is saved, although it is never stored permanently; closing the wizard or a failed analysis leaves the file forever, and the delete in `api_salva_attivita` runs before `att.save()`, so a failed save makes the retry answer "File temporaneo non trovato. Ricarica il WPS.". Delete the file in `api_analizza_wps` right after the measurements are extracted (in a `finally`), and remove `tmp_path` from the response, from the wizard payload and from `api_salva_attivita` (the existence check, the delete and the docstring sentence about moving the file).
