# build_suggestion re-implements pick_free_spare with a different window

ui/services/overlap_reassign.py `build_suggestion`: it re-implements the composition `pick_free_spare` (same file) offers as "one rule" for every automatic substitution, with a different window. `pick_free_spare` computes `occupied` over `candidate_window(att.data_inizio, att.data_fine, att)`, `build_suggestion` over the raw planned dates (`start = blocked.data_inizio; end = blocked.data_fine`), while its candidate list comes from `_blocked_availability`, which uses `candidate_window`. For a blocked activity whose planned start is already past, a spare that was held by another activity between the planned start and yesterday is discarded by the delay-overlap swap but would be picked by maintenance and by the tablet scan. Call `pick_free_spare(tipo, uid, blocked)` inside the loop of `build_suggestion` and drop the inline copy.
