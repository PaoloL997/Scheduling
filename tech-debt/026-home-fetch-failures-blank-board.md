# Home page stays blank when /api/gantt/ fails

ui/templates/ui/index.html `loadKanban` and `loadFilterOptions`, ui/static/ui/gantt.js `loadFromUrl`: the Home page reads `/api/gantt/` with `fetch(...).then(r => r.json())` and no `r.ok` check; the two template functions end with `.catch(() => {})` and `loadFromUrl` has no catch. When the session has expired (the endpoint answers a 302 to the HTML login page) or the server answers 500, the kanban and the Gantt stay empty with no message. Check `r.ok` and `r.redirected`, reload the page when the answer is the login redirect, and otherwise show one error line in `#kanban-board` and in the Gantt area ("Impossibile caricare le attività. Ricarica la pagina."). In the same change build the filter options from `kanban.tasks` instead of fetching `/api/gantt/` a second time in `loadFilterOptions`.
